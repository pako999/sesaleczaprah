# Zbiralnik prahu pri vrtanju

Hitra večjezična one-page prodajna stran za zbiralnik prahu pri vrtanju.

## Jeziki
- Slovenščina
- English
- Deutsch
- Español

## Pred Vercel objavo
V `site-config.js` nastavi prodajno ceno, checkout povezavo in kontaktni e-mail.

## Vercel
Repo lahko neposredno uvoziš v Vercel. `vercel.json` je že pripravljen.
